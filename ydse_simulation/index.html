Young's Double Slit Experiment — Theoretical Principles

1. Wave Superposition & Path Difference

When light from a monochromatic coherent source passes through two narrow slits S₁ and S₂ separated by distance d, each slit acts as a secondary source of spherical wavelets (Huygens' Principle). The optical path difference Δx to a point P at distance y on a screen placed at distance D is:

Δx = S₂P − S₁P ≈ (y · d) / D

2. Conditions for Maxima and Minima

  • Constructive Interference (Bright Fringes / Maxima): Occurs when waves arrive in phase, i.e., path difference is an integral multiple of wavelength:
    Δx = n · λ ⇒ y_n = (n · λ · D) / d,   where n = 0, ±1, ±2, ...
  • Destructive Interference (Dark Fringes / Minima): Occurs when waves arrive out of phase by π radians, i.e., path difference is an odd half-integral multiple of wavelength:
    Δx = (2n − 1) · (λ / 2) ⇒ y_n' = (2n − 1) · (λD / 2d),   where n = ±1, ±2, ...

3. Fringe Width (β) & Angular Width (θ)

The separation between any two successive bright fringes (or two successive dark fringes) is constant across the interference pattern:

β = y_{n+1} − y_n = (λ · D) / d

The angular fringe width subtended at the slits is independent of the screen distance D:

θ = β / D = λ / d

4. Insertion of a Thin Transparent Sheet (Mica / Glass)

If a thin transparent film of thickness t and refractive index μ is inserted in front of slit S₁, light slows down in the medium ($v = c/\mu$). The additional optical path introduced is $(\mu - 1)t$. This shifts the entire fringe pattern upward toward the side with the sheet by:

Δy_{shift} = (D / d) · (μ − 1) · t

Importantly, the fringe width β remains completely unaltered; only the position of the central zeroth-order maximum shifts.

5. White Light vs. Monochromatic Light

With monochromatic light, identical bright and dark fringes extend outward. With white light (polychromatic):

  • The central maximum ($n=0$) has zero path difference for all wavelengths, producing a sharp white central fringe.
  • The first bright fringe closest to center is violet (since $\lambda_{violet} < \lambda_{red}$ so $\beta_{violet} < \beta_{red}$), followed by blue, green, and red on the outside.
  • After a few colored fringes, overlapping maxima of different wavelengths wash out into uniform white illumination.
