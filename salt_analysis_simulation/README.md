# Systematic Qualitative Inorganic Salt Analysis Virtual Lab

An interactive STEM virtual chemistry laboratory simulating NCERT / CBSE Class 11 & 12 Qualitative Inorganic Salt Analysis to identify basic radicals (cations) and acidic radicals (anions).

## Key Features
- **Anion Systematic Analysis**:
  - **Dilute $\text{H}_2\text{SO}_4$ Group**: Carbonate ($\text{CO}_3^{2-}$ brisk effervescence of colorless $\text{CO}_2$ gas turning lime water milky).
  - **Concentrated $\text{H}_2\text{SO}_4$ Group**: Chloride ($\text{Cl}^-$ pungent fumes, curdy white precipitate with $\text{AgNO}_3$ soluble in $\text{NH}_4\text{OH}$, chromyl chloride test $\text{CrO}_2\text{Cl}_2$ orange-red vapors).
  - **Special Group**: Sulfate ($\text{SO}_4^{2-}$ heavy white precipitate with $\text{BaCl}_2$ insoluble in conc. $\text{HCl}$).
- **Cation Systematic Group Analysis**:
  - **Group 0 ($\text{NH}_4^+$)**: Pungent ammonia smell with $\text{NaOH}$, reddish-brown precipitate with Nessler's Reagent ($K_2[HgI_4]$).
  - **Group II ($\text{Cu}^{2+}$)**: Black $\text{CuS}\downarrow$ with $\text{H}_2\text{S}$, deep royal blue solution $[Cu(NH_3)_4]^{2+}$ with excess ammonium hydroxide.
  - **Group III ($\text{Fe}^{3+}, \text{Al}^{3+}$)**: Brown $\text{Fe(OH)}_3\downarrow$ turning intense Prussian Blue with potassium ferrocyanide; $\text{Al}^{3+}$ gelatinous white precipitate giving positive Blue Lake test with alizarin.
  - **Group V ($\text{Ba}^{2+}, \text{Ca}^{2+}$)**: Apple-green flame test ($\text{Ba}^{2+}$), brick-red flame test ($\text{Ca}^{2+}$).
- **Interactive Workbench**: Test tubes, droppers with reagents, Bunsen burner flame loop test, and real-time precipitation rendering.
- **Blind Mystery Salt Detective Mode**: Deduce unknown combinations (e.g. $\text{NH}_4\text{Cl}$, $\text{CuSO}_4$, $\text{CaCO}_3$, $\text{FeCl}_3$) using systematic flowchart logic.
- **Soft Light-Blue Academic Aesthetics**: Conforms to study environment law, zero external dependencies.
